# 사진 촬영 도우미 · Photo Field Mobile

모바일 Obsidian에서 오프라인으로 **심도·화각, 수동 플래시의 적정 노출 예상 거리와 조사 범위**를 확인하고 일반 Markdown 노트로 저장하는 플러그인. iOS·Android 공용 ItemView UI이며 `isDesktopOnly:false`는 모바일 전용 강제가 아니라 모바일 설치 허용이다.

[depth-of-field](https://github.com/jherr/depth-of-field), **Jack Herrington**, MIT ©2026의 심도·화각 계산과 시각화를 참고하여 모바일 Obsidian용으로 수정·재구현하고 플래시 계산·장비 프리셋·노트 저장을 확장했다. 원작자의 공식 또는 후원 플러그인이 아니다. 참고 SHA: `c75dd6d40e4a96e96fd38e57657fe4b9737bf776`.

## 모바일 BRAT 설치 (권장)

GitHub: https://github.com/kimchi-kang/obsidian-photo-field-mobile

1. 모바일 Obsidian → 설정 → 커뮤니티 플러그인에서 **BRAT**를 설치·활성화한다.
2. BRAT → **Add Beta plugin**에 `kimchi-kang/obsidian-photo-field-mobile`을 입력하고 최신 버전으로 설치한다.
3. **Enable after installing**을 켜거나 커뮤니티 플러그인에서 **사진 촬영 도우미**를 활성화한다.
4. 화면의 **⋯ / 리본 메뉴 → 사진 촬영 도우미 열기**를 누른다. MIA Study와 같은 Obsidian 리본 진입 방식이다. 명령 팔레트의 **사진 촬영 도우미: 촬영 계산 열기**도 사용할 수 있다.
5. BRAT 업데이트 확인으로 새 버전을 받을 수 있다. 설치·업데이트에만 인터넷이 필요하며 계산·저장은 오프라인으로 작동한다.

모바일 메뉴에 항목이 없으면 해당 기기에서 설치·활성화 여부를 먼저 확인한다. 데스크톱의 설치 폴더가 모바일에 자동 전달되는지는 동기화 설정에 따라 다르므로 각 기기에서 BRAT로 설치하는 방법을 권장한다.

## 수동 설치와 실행

1. ZIP의 `photo-field-mobile` 폴더를 **사용할 보관함의 `.obsidian/plugins/`** 아래에 복사한다. `main.js`, `manifest.json`, `styles.css`가 바로 그 폴더 안에 있어야 한다. 라이선스·고지 파일과 vendor 폴더도 함께 보관한다.
2. Obsidian 설정 → 커뮤니티 플러그인에서 **사진 촬영 도우미**를 활성화한다. 이미 앱이 열려 있었다면 다시 시작하거나 플러그인 목록을 새로 읽는다.
3. 명령 팔레트 → **사진 촬영 도우미: 촬영 계산 열기**, 또는 카메라 리본 아이콘. 모바일에서는 도구막대에 이 명령을 추가해도 된다.
4. **현재 계산을 노트로 저장** 버튼은 보관함 `사진 촬영 계산/`에 새 `.md`를 만든다. 기존 파일을 덮어쓰지 않는다. 명령 팔레트의 저장 명령도 제공한다.

iOS: Files에서 보관함을 찾고 Mac/PC로 `.obsidian/plugins/photo-field-mobile`을 복사한 후 보관함 전체를 동기화하는 방식이 편리하다. 숨김 폴더 접근이 어려우면 데스크톱에서 설치한 뒤 **설정/플러그인 폴더도 동기화하는 수단**을 사용한다. Obsidian Sync에서는 플러그인·설정 동기화 선택을 확인한다. Android: 보관함 폴더에 접근 가능한 파일 관리자 또는 USB로 복사한다. Android의 보관함 접근 권한과 저장 위치는 OS/앱 구성에 따라 다르다. 설치/동기화 이후 계산과 저장에는 인터넷이 필요 없다. Obsidian 자체의 동기화 동작은 플러그인과 별개다.

플러그인은 설치한 보관함 안에서만 작동한다. 검증 결과는 `docs/VALIDATION.md`에 기록한다. 현재 버전 **1.1.0**의 버그 수정 내역은 [CHANGELOG.md](CHANGELOG.md)에 정리했다. 기존 보관함 내용이나 다른 플러그인을 변경하지 않는다.

## 30초 사용 예

기본 GN40은 **계산 연습용 가상값이며 특정 장비 사양이 아니다**. 촬영 전에 설명서/실측의 줌별 GN으로 교체한다. 기본 지원 출력 목록 역시 일반적인 예시이므로 장비에 맞게 수정한다.

- GN40 **m**, ISO100·최대 출력·**50mm 측정 줌**, f/4, ISO100: 출력 1/1이면 적정 노출 예상 거리 10m, 1/4이면 5m, 1/16이면 2.5m.
- 1/4에서 피사체가 플래시로부터 10m라면 예상 차이 −2EV. 2.5m라면 +2EV. 빛이 5m에서 끝난다는 뜻이 아니다.
- 조리개를 f/8로 바꾸면 거리는 2.5m가 되고 심도도 동시에 갱신된다.
- `온카메라`를 해제하면 카메라 거리와 플래시 거리를 각각 입력한다. 위치·방향 정보가 없으므로 공간 중첩은 계산하지 않는다.
- 줌을 바꾸면 **그 줌의 GN**이 필요하다. `GN이 측정된 줌`이 선택 줌과 다르면 거리를 계산하지 않는다. 장비 최대 GN을 모든 줌에 사용하면 안 된다.

## 원본 장면 구성과 조작

**심도·화각** 탭은 원본처럼 촬영자·피사체·회색 화각 원뿔·분홍 심도를 한 장면으로 보여주고, 근거리/원거리/전체 심도/과초점 네 카드를 배치한다. 피사체를 좌우로 드래그하거나 거리·실제 초점거리·조리개 슬라이더와 숫자 칸으로 조절한다. **과초점 맞추기**로 해당 거리에 초점을 옮길 수 있다. 원본의 자산 대신 직접 작성한 단순 SVG 기호를 사용하며 한국어·Obsidian 테마와 44px 터치 영역에 맞춰 배치했다.

**통합** 탭은 여기에 플래시 예상 거리와 조사각·노출 구간을 함께 표시한다. **플래시** 탭에서도 촬영 장면과 빠른 조절을 사용할 수 있다. 오프카메라에서는 플래시 거리 축을 분리하여 정확한 공간 중첩을 주장하지 않는다. 화면 밖의 유한 거리는 화살표와 수치로 표시한다.

## 입력·단위·프리셋

- 센서 가로/세로 **mm**: 36×24 풀프레임, 23.6×15.6 APS-C 예시, 17.3×13 MFT, 사용자 지정. APS-C는 제조사마다 다르므로 필요하면 직접 수정.
- 초점거리 **실제 mm**를 입력. 35mm 환산값은 정보로만 표시하며 심도에는 실제 초점거리 사용.
- 조리개는 f-number, ISO는 촬영 ISO. 카메라와 플래시 거리는 각각 **m**.
- GN은 **ISO100·최대 출력·선택 줌** 기준. m/ft 선택 시 숫자도 변환한다. 내부 기준은 m이며 1ft=0.3048m.
- 출력 1/n은 표준 선택 또는 사용자 n≥1. 장비 최소 출력 분모와 **실제 지원 분모 목록**을 입력한다. 필요 출력이 최대보다 크거나 최소보다 작으면 경고. 가까운 지원 단계는 EV 오차가 작은 단계를 택하며 잔여 오차를 표시한다. 중간 출력 입력은 지원 목록과 다를 수 있어 가장 가까운 실제 단계와 오차를 반드시 확인한다.
- 허용 범위 기본 ±1EV, 0 초과 5EV 이하. 노출 허용 구간은 d/2^(E/2)~d×2^(E/2). 0~d 전체를 적정으로 칠하지 않는다.
- 추가 손실 L≥0 stop, 기본 0. 확산판 등의 보정 추정치를 추가할 때 GN에 이미 반영된 손실을 다시 넣지 않는다.
- CoC 기본값=센서 대각/1500 **mm**. 관찰 거리·출력 크기·시력·확대율에 따라 달라지는 경험칙이며 픽셀 단위 선명도 기준이 아니다. 사용자 CoC 가능.
- 플래시 조사각: 수평/수직 **도** 직접 입력 권장. 줌mm 변환은 **36×24mm 풀프레임 커버리지 가정**을 명시하는 근사 모드다. 제조사 기준 포맷을 확인한 모델별 변환값은 내장하지 않는다.
- 내 장비 프리셋: 이름, 측정 조건, 출처 URL/페이지 또는 실측 방법, `줌mm,GN`을 한 줄에 하나씩 입력. 현재 GN 단위로 읽고 m로 저장. 최소 출력/지원 단계도 함께 저장. 장비를 선택하고 `현재 줌 GN 적용`을 누른다. 해당 줌 행이 없으면 수동 입력 요청. 다른 줌 GN의 보간이나 최대 GN 대입 없음. 프리셋은 추가·삭제 가능하며 수정은 새로 저장 후 이전 것을 삭제.
- 마지막 입력·화면 모드·장비 표는 `loadData/saveData`로 보존. 빈 숫자는 계산하지 않으며 해당 칸의 마지막 유한한 숫자를 저장에 사용한다. 다른 입력과 장비 프리셋의 저장은 계속된다. 값은 드래그 없이 직접 입력할 수 있고 조리개·거리는 슬라이더도 제공.

## 계산 모델과 공식

G=선택 줌 ISO100·최대출력 GN(m), p=출력 비율=1/n, S=ISO, N=f-number, L=추가 손실 stop, r=플래시 거리 m.

```
유효 GN = G × √p × √(S/100) × 2^(−L/2)
d = 유효 GN / N
필요 조리개 = 유효 GN / r
필요 출력 = (N × r / G)² × (100/S) × 2^L
노출 차이 EV = 2 × log₂(d/r)
```

EV 양수=예상 과다, 음수=예상 부족. 1/n 출력의 거리는 최대 출력 거리의 **1/√n**. GN과 출력으로 절대 lux/lumen/joule을 추정하지 않는다. 거리별 표는 d의 0.5/0.707/1/1.414/2배에서 노출 차이를 표시한다.

광학 계산 f, s, c는 모두 mm로 맞춘 뒤 m로 표시한다.

```
H = f²/(N × c) + f
h = H − f
근거리 = h × s / (h + s − f)
원거리 = h × s / (h − s + f), s ≥ H이면 ∞
전체 심도 = 원거리 − 근거리
화각 = 2 × atan(센서 길이/(2 × f)), 도로 변환
평면 범위 = 2 × 거리 × tan(해당 각/2)
```

H는 무한대에서 들어오는 빛의 착란원이 c가 되는 첫 정의의 과초점거리다. H에 +f를 포함하므로 근/원거리에는 h=H−f를 일관되게 사용한다. 초점거리는 렌즈 주평면 기준의 이상화다. s≤f는 이 모델에서 불가능하므로 오류로 처리한다. 화면 최대 거리를 넘는 **유한값은 →와 숫자**, 수학적 무한대만 ∞로 표시. CoC/화면 범위는 서로 독립적이다.

회절: 파장 550nm 가정, Airy 지름≈2.44λN을 CoC와 비교하는 근사 안내. 렌즈 수차, 센서 샘플링, 출력 조건을 반영한 절대 선명도 판정이 아니다.

## 지원 조건과 한계

**수동 플래시·직접광·일반 동조·중심부 노출**의 GN 모델이다. TTL/HSS/바운스/소프트박스/근거리 대형 광원 선택 시 기본 공식의 거리를 비우고 계산 불가를 표시한다. 손실값 하나로 모든 상황을 정확히 보정할 수 없다. 실측, 제조사 조건, 시험 촬영과 히스토그램을 함께 확인한다.

환경광, 셔터속도와 동조 한계, 피사체 반사율, 실제 플래시 배광·페더링·광축, 장비 오차를 모델링하지 않는다. 원뿔은 **기하학적 커버리지**, 빗금/점선은 노출 허용구간을 읽기 위한 표식이며 정확한 밝기 지도나 빛의 끝이 아니다. 같은 위치·같은 방향에서만 프레임 대비 범위를 비교한다. 오프카메라에서는 각 광학축에 수직인 **별도 거리 평면**을 표시한다.

렌즈는 직선투영 박막렌즈. 어안렌즈, 틸트, 접사 동공배율, 포커스 브리딩·렌즈 내부 보정은 반영하지 않는다. GN과 플래시 줌이 고정되어 있으면 센서/렌즈 변경만으로 플래시 거리가 변하지 않는다. 자동 줌 기능은 제공하지 않는다.
