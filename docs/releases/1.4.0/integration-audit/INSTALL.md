# 사진 촬영 도우미 1.4.0 · 검증된 설치 후보

공개 배포 전 후보입니다. 이번 변경에 대한 실사용 설치 승인은 아직 받지 않았습니다.

## 설치

1. Obsidian에서 사진 촬영 도우미를 끕니다.
2. 사용할 보관함의 `.obsidian/plugins/photo-field-mobile/` 폴더 전체를 다른 위치에 복사해 보관합니다. 특히 기존 `data.json`이 필요합니다.
3. 이 ZIP의 `photo-field-mobile/` 폴더 안 파일을 플러그인 폴더에 복사합니다. 기존 data.json을 삭제하거나 덮어쓰지 마세요. ZIP에는 사용자 데이터가 없습니다.
4. 플러그인을 다시 켜고 기존 입력·장비·작성 중 장비 초안이 유지되는지 확인합니다.

## 현장 사용

‘즐겨찾기·거리 관리’에서 현재 촬영 조건을 이름 붙여 저장합니다. ‘거리도 저장’을 체크하지 않으면 현재 카메라 거리를 유지합니다. 체크하면 카메라 초점 거리와 별도 플래시 거리 모두를 저장하며 온카메라에서는 연동 거리입니다. 저장 후 이름 변경·현재 조건 갱신·삭제·마지막 삭제 복구를 할 수 있습니다.

‘현장 간편 화면으로’를 누르면 선택을 기억합니다. 촬영 즐겨찾기 → 내 거리 → EV 확인 → 권장 출력 적용은 3번 탭입니다. 약하게/강하게는 실제 지원 출력 단계로 이동합니다. 오프카메라에서 내 거리는 플래시→피사체 거리만 바꿉니다. 상세 화면으로 언제든 이동할 수 있습니다.

존 목표를 이름 붙여 저장하면 존 즐겨찾기 → 현재 렌즈 조건의 제안 확인 → 명시적 설정 적용은 2번 탭입니다. 즐겨찾기 선택 자체는 실제 초점 거리·조리개를 바꾸지 않습니다. 화면 크기와 위치에 따라 세로 스크롤이 필요할 수 있습니다.

촬영 적용 취소는 바뀐 항목만, 출력 취소는 출력만 되돌립니다. 이후 겹치는 값을 바꾸면 해당 취소가 만료됩니다. 즐겨찾기 삭제 복구는 별개이며 현재 화면 세션에서 마지막 삭제 한 건을 복구합니다.

참조 장비가 삭제되거나 사양이 바뀌면 GN 계산을 차단합니다. 삭제된 장비를 복구하거나 명시적으로 현재 장비를 선택하고 즐겨찾기를 갱신하세요. 저장 실패는 상단 안내의 ‘저장 재시도’로 최신 상태를 다시 저장합니다.

## 데이터·복구

기존 version 2에 field version 1이 추가됩니다. 기존 입력·장비·초안·존 설정을 보존하고 업데이트 직전 전체 데이터는 migrationBackup에 보관합니다. 새 스키마는 안정적인 ID·m 단위 숫자를 쓰며 지원하지 않는 미래 버전은 로드를 중단하여 덮어쓰지 않습니다. 촬영/존 즐겨찾기는 빈 목록으로 시작합니다.

이전 1.3.4로 돌아가려면 플러그인을 끄고 이전 프로그램 파일과 **설치 전 백업한 data.json을 함께** 복구하세요. 이전 버전은 새 field 데이터를 이해하지 못합니다. 현재 data.json도 별도 복사하면 새 즐겨찾기를 나중에 복원할 수 있습니다.

## 검증 범위

strict 타입 검사·빌드와 자동 회귀를 통과했습니다. 별도 테스트 보관함/프로필의 macOS Obsidian app.emulateMobile(true), CDP 모바일 뷰포트·터치로 신규 흐름, 기존 저장·거리·장면·슬라이더 회귀와 360/390px 세로·가로·두 테마·큰 글씨를 확인했습니다. 계산 엔진·단위 변환·존 역산을 재사용합니다.

실제 iOS/Android 키보드·IME·접근성·안전영역·동기화·강제 종료와 실제 플래시 노출은 미확인입니다. 기본 GN40은 연습용 가상값입니다. MIT 라이선스와 원작 라이선스·고지를 함께 보관하세요.

## 통합 검증 후 후보

버전은 1.4.0을 유지합니다. 새 기능은 추가하지 않았습니다. 출력 조절을 결과·권장 출력 옆에 모으고 반복 요약·관련성이 낮은 상세 바로가기를 간편 화면에서 정리했습니다. 존은 목표 선택·제안·적용을 먼저 표시하며 현재 거리 조작은 그 다음에 있습니다. 변경 내역은 1/8 → 1/16, f/4 → f/5.6처럼 실제 표기로 확인합니다. 큰 글씨에서 존 적용 후 화면 위치가 저절로 이동하던 문제를 수정했습니다.

현재 소스의 자동 검사 92개, 기존 모바일 회귀 41묶음, 연속 사용 10개 시나리오, 화면 조합 12개, 실제 장비 편집·삭제·복구, 정상 앱 재실행을 확인했습니다. 390×844 기본 글씨의 촬영 3탭·연속 출력 조절 2탭·존 2탭에는 설정 이동이나 키보드, 스크롤 왕복이 없었습니다. 360px·큰 글씨·가로에서는 세로 스크롤이 필요합니다.

이 ZIP은 기존 첫 구현 후보와 구분되는 통합 검증 후보입니다. 실사용 설치·공개 배포는 아직 수행하지 않았습니다.
