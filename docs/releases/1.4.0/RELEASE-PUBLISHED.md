촬영 조건을 불러와 거리를 선택하고 노출을 확인한 뒤 바로 조절하는 흐름을 연결했습니다.

- 촬영 즐겨찾기: 조건 저장·이름 변경·현재 조건 갱신·삭제 복구·변경 확인·안전한 적용 취소. 거리는 기본 유지하며 선택한 경우에만 카메라·별도 플래시 거리를 포함합니다.
- 현장 간편 화면: 기존 계산 상태·실제 촬영 장면을 유지하고 결과와 핵심 조절을 모았습니다.
- 내 거리: 직접 추가·수정·정렬·삭제. 오프카메라에서는 플래시 거리만 변경합니다.
- 약하게/강하게: 실제 지원 출력 목록과 이론 출력의 양방향 이동·경계를 따릅니다.
- 존 목표 즐겨찾기: 현재 렌즈·센서·CoC·조리개 제한으로 다시 역산하고 명시적으로 적용합니다.

통합 검증에서 출력 조절의 스크롤 왕복, 출력·실제 조리개 변경 표기, 존 목표 우선 배치와 큰 글씨 적용 후 화면 위치를 다듬었습니다. 390px 기본 화면에서 촬영 3탭·출력 조절 2탭·존 2탭을 확인했습니다. 작은 화면·큰 글씨·가로는 세로 스크롤을 사용합니다.

기존 입력·장비·초안·존 설정을 보존하는 추가 마이그레이션과 미래 스키마 보호, 저장 실패 재시도를 유지합니다. 누락·변경된 장비의 오래된 GN을 조용히 대입하지 않습니다.

자동 회귀 92개, 현재 코드의 모바일 회귀 41묶음, 통합 시나리오 10개와 화면 12조합·정상 테스트 앱 재실행을 통과했습니다. 실제 iOS/Android 키보드·안전영역·동기화·실제 플래시 노출은 별도 확인이 필요합니다.
