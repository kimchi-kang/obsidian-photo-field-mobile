# 사진 촬영 도우미 1.4.0 설치·복구

통합 사용 흐름 검증을 마친 1.4.0입니다. 승인된 통합 후보와 main.js·manifest.json·styles.css는 동일합니다. 설치 전 기존 플러그인 폴더와 data.json을 백업하세요.

## 업데이트

BRAT에서 `kimchi-kang/obsidian-photo-field-mobile`의 latest 업데이트를 확인합니다. 수동 설치 시 플러그인을 끄고 ZIP의 photo-field-mobile 폴더 안 프로그램 파일과 라이선스를 `.obsidian/plugins/photo-field-mobile/`에 복사합니다. **기존 data.json은 지우거나 교체하지 않습니다.** 다시 활성화한 뒤 기존 입력·장비·초안을 확인하세요.

## 현장 사용

‘즐겨찾기·거리 관리’에서 현재 촬영 조건을 이름 붙여 저장합니다. 기본적으로 현재 거리를 유지합니다. ‘거리도 저장’을 선택하면 카메라 초점 거리와 별도 플래시 거리 모두를 포함합니다. 온카메라는 연동 거리입니다.

간편 화면에서 촬영 즐겨찾기 → 내 거리 → EV 확인 → 권장 출력 적용은 기본 3탭입니다. 약하게/강하게는 장비의 실제 지원 목록을 따릅니다. 오프카메라에서 거리 버튼은 플래시 거리만 바꿉니다. 실제 조리개 조절과 기존 상세 설정도 계속 접근할 수 있습니다.

존 즐겨찾기 → 현재 렌즈 조건의 제안 확인 → 명시적 설정 적용은 2탭입니다. 목표 선택만으로 실제 초점 거리·조리개가 바뀌지 않습니다. 작은 화면·큰 글씨·가로에서는 세로 스크롤이 필요할 수 있습니다.

## 저장·되돌리기

촬영 적용 취소는 바뀐 항목만, 출력 취소는 출력만 되돌립니다. 이후 같은 항목을 바꾸면 해당 취소가 만료됩니다. 촬영/존 삭제 복구는 적용 취소와 별개이며 현재 화면 세션에서 마지막 한 건을 복구합니다.

장비가 삭제되거나 사양이 변경된 즐겨찾기는 GN 계산을 차단합니다. 장비 삭제 복구 또는 명시적 장비 선택, 확인 후 즐겨찾기 갱신으로 해결하세요. 저장 실패는 ‘저장 재시도’로 최신 상태를 다시 저장합니다.

기존 version 2에 field version 1을 추가합니다. 기존 입력·장비·초안·존 설정을 유지하고 이전 데이터는 migrationBackup에 보존합니다. 미래 스키마는 덮어쓰지 않습니다. 촬영·존 즐겨찾기는 빈 목록으로 시작하며 기본 GN40은 기존 연습용 가상값입니다.

## 1.3.4 복구

플러그인을 끄고 이전 1.3.4 프로그램 파일과 **업데이트 전 백업한 data.json을 함께** 복구합니다. 1.3.4는 새 즐겨찾기 데이터를 이해하지 못하므로 현재 data.json도 별도로 보관하세요. 이 설치 ZIP에는 사용자 데이터가 포함되지 않습니다.

자동 회귀 92개와 현재 코드의 모바일 회귀 41묶음, 통합 시나리오 10개·화면 12조합·정상 테스트 앱 재실행을 확인했습니다. 실제 iOS/Android의 키보드·접근성·동기화·강제 종료와 실제 플래시 노출은 미검증입니다. MIT 및 원작 라이선스·고지를 함께 보관하세요.
