# 사진 촬영 도우미 1.4.0 · 설치 후보

2026-11-02. 공개 배포 전 검증 후보입니다. 실사용 설치·GitHub 공개 배포는 이번 변경에 대한 별도 승인 후 진행합니다.

- **촬영 즐겨찾기**: 이름을 붙여 촬영 조건을 저장·적용합니다. 기본은 현재 거리를 유지합니다. ‘거리도 저장’은 카메라 초점 거리와 별도 플래시 거리 모두를 포함하며 온카메라에서는 연동 거리입니다. 관리에서 이름 변경, 같은 거리 포함 범위로 현재 조건 갱신, 삭제·마지막 삭제 복구를 할 수 있습니다.
- **현장 간편 화면**: 같은 입력·계산을 사용합니다. 촬영 조건·내 거리 → EV·권장 출력 → 출력·실제 조리개 조절로 이어집니다. 작동하는 촬영 장면은 조절부 다음에 유지합니다. 간편/상세 선택은 재실행 뒤 복원합니다.
- **내 거리**: 기본 1/1.5/2/3/5m. 관리에서 추가·수정·앞뒤 정렬·삭제합니다. 첫 5개 다음은 더보기입니다. 심도·존에서는 현재 초점 거리, 온카메라에서는 연동 거리, 오프카메라에서는 플래시 거리만 바꿉니다. 존 목표 구간은 바꾸지 않습니다.
- **약하게/강하게**: 실제 지원 분모 목록을 따릅니다. 이론 출력의 양쪽에서 가장 가까운 실제 출력으로 이동하고 경계에서는 비활성화합니다. GN이 불완전해도 알려진 지원 단계는 선택할 수 있으나 계산 결과는 차단합니다. 장비 삭제로 목록을 확인할 수 없으면 단계 이동도 차단합니다.
- **존 목표 즐겨찾기**: 이름·근거리·원거리/무한대만 보관합니다. 선택하면 현재 센서·렌즈·CoC·조리개 한계로 역산하고, ‘역산 결과를 현재 설정에 적용’을 눌러야 초점 거리·실제 조리개가 바뀝니다. 불가능한 목표는 기존 이유·대안 안내를 유지합니다.

촬영 즐겨찾기는 촬영 조건 묶음, 장비 프리셋은 장비 사양, 존 즐겨찾기는 목표 구간입니다. 예시 촬영/존 즐겨찾기는 자동 생성하지 않습니다. 기본 GN40은 기존과 같이 연습용 가상값입니다.

## 사용 예

사전에 이름을 저장하고 간편 화면을 선택합니다.

1. **주간 스냅 → 3m → EV 확인 → 권장 출력 적용**: 3번 탭. 설정 화면 방문·키보드 호출 없음. 화면 위치와 글씨 크기에 따라 세로 스크롤이 필요합니다.
2. **거리 2~5m → 역산 제안·현재 값과 변경값 확인 → 설정 적용**: 2번 탭. 목표 선택 자체는 실제 초점 거리·조리개를 바꾸지 않습니다.

## 취소와 복구

- 촬영 적용 내역을 펼치면 실제 변경 항목의 전/후 값을 확인합니다. 적용 취소는 바뀐 항목만 돌립니다. 해당 항목을 이후 수정하면 이 취소만 만료하고 안내합니다. 적용된 이름과 ‘이후 수정됨’ 상태를 표시합니다.
- 출력 적용 취소는 출력 분모만 돌립니다. 이후 출력 변경 또는 새 촬영 즐겨찾기 적용 시 이전 출력 취소가 만료됩니다. 촬영 취소는 이후 별도로 바꾼 거리를 덮어쓰지 않습니다.
- 촬영/존 삭제 복구는 적용 취소와 별개입니다. 현재 화면 세션에서 마지막 한 건을 복구합니다.
- 삭제된 장비 또는 사양이 변경된 장비를 참조하면 GN 계산을 차단하고 불완전 상태를 표시합니다. 장비 삭제 복구, 명시적 장비 선택 또는 확인 후 촬영 즐겨찾기 갱신으로 해결합니다. 장비 이름 변경만으로 사양 변경으로 취급하지 않습니다.
- 저장 실패는 간편 화면 상단과 기존 저장 영역에 표시합니다. ‘저장 재시도’로 최신 변경을 합쳐 다시 저장합니다.
