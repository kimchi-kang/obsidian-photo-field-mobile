# 1.4.0 설치·공개 배포 기록

사용자가 통합 검증 후보의 실사용 설치와 공개 배포를 승인했습니다.

## 실사용 설치 완료

- 기존 1.3.4 플러그인 폴더 전체를 로컬 비공개 dist 아래에 백업했습니다.
- Obsidian 설정에서 사진 촬영 도우미만 비활성화하고 검증된 1.4.0 프로그램·라이선스 파일을 교체했습니다.
- 플러그인 목록 새로고침에서 1.4.0을 확인한 뒤 재활성화했습니다. 실사용 촬영 화면에서도 v1.4.0과 새 조작을 확인했습니다.
- 설치 전·복사 후·활성화 후·화면 확인 후 data.json의 SHA256이 동일합니다. 입력·장비·초안이 보존됐으며 사용자 노트와 촬영값을 검사 목적으로 조작하지 않았습니다.
- 개인 보관함 경로·실제 설정·해시는 ignored dist의 비공개 설치 기록에만 보관합니다. 공개 소스나 릴리스에 포함하지 않습니다.

## 공개 배포

- 승인된 통합 후보의 세 실행 파일을 그대로 사용합니다. 버전은 1.4.0입니다.
- 공개용 ZIP은 같은 실행 파일·라이선스에 승인/설치 안내를 갱신한 INSTALL.md를 포함합니다. 최초 검증 후보 ZIP은 보존합니다.
- main.js·manifest.json·styles.css·설치 ZIP·라이선스·1.3.4 복구 ZIP·SHA256 목록을 제공합니다. data.json은 포함하지 않습니다.
- 최초 후보 및 통합 검증 기록의 ‘미승인/미설치’ 표시는 당시 상태이며 이 문서가 승인 이후 상태입니다.
- 이전부터 존재한 1.3.4 배포 후 기록과 BRAT 복구 자료·사용자 테스트 수정은 이번 구현 커밋에 섞지 않습니다.

릴리스 첨부 파일과 원격 태그 검증 결과는 publication.json에 기록합니다.

## 공개 완료

- 공개 릴리스: https://github.com/kimchi-kang/obsidian-photo-field-mobile/releases/tag/1.4.0
- 태그 커밋: `f13baef8f032ee62387ea26ff9fcdbc0be019a4c`.
- GitHub Latest 1.4.0, draft=false, prerelease=false를 확인했습니다. BRAT latest로 업데이트할 수 있습니다.
- 첨부 8개를 다시 내려받아 로컬 배포 파일과 일치함을 확인했습니다. 공개 manifest.json은 인증 없이도 다운로드해 동일성을 확인했습니다.
- 실행 파일은 승인된 통합 후보·실사용 설치본·검증본과 동일합니다. 이전 1.3.4 릴리스와 비공개 전체 백업을 보존했습니다.

최종 저장 확인에서는 새 field 스키마와 migrationBackup 추가만 관측됐습니다. 기존 입력·장비·초안 등 원래 데이터는 같고, migrationBackup은 설치 전 전체 데이터와 일치합니다. 정상적인 추가 마이그레이션이며 기존 설정을 되돌리거나 덮어쓰지 않았습니다.
