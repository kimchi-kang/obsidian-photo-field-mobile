# 1.3.4 배포 후 실행 검증 · 부분 완료

2026-11-02, 기준 HEAD612b236, 공개 태그1.3.4=f8f3d4d. Codex AGENTS와 최신 배포 기록을 확인했다. 이미 완료한 설치·공개 배포는 반복하지 않았으며 제품 실행 파일·버전·릴리스 첨부 파일은 변경하지 않았다. 기존 미추적 BRAT 기록도 보존했다.

## 실사용 보관함

- 컴퓨터 제어 최초 연결은 성공했다. 리본에서 촬영 도우미를 열어 실제 장면·계산 결과·4개 탭 레이블·v1.3.4를 직접 확인했다. 최초 화면에 흰 화면·로딩 정지·오류 알림은 보이지 않았다.
- 버전 문자열 외에1.3.4의 상단 실제 조건 요약·질문형 존 흐름·정리된 목표/역산/렌즈 제한 구성·탭별 저장 이름을 확인했다. 설치된 main.js·manifest.json·styles.css의 해시는 이번에 다시 받은 공개 배포본과 일치했다. 실행된 JS 바이트를 직접 추출한 검사는 아니므로 런타임 동일성 근거의 한계는 남긴다.
- 플래시 탭 전환은 저장된 탭 상태에 반영됐지만, 컴퓨터 제어는 기존 존 화면과 서로 모순되는 활성 탭 접근성 정보를 반복 반환했다. 촬영 화면 닫기/재열기 시 창 제목은 다른 노트→촬영 도우미로 변경됐으나 캡처/접근성 하위 트리는 이전 값을 유지했다. 따라서 **실사용4탭의 새 렌더링과 닫기 후 재진입 최종 화면 검증은 미완료**다.
- 원래 존 탭으로 복원했다. 탭 복원 직후 data.json 전체가 검사 전과 **바이트 단위로 동일**함을 확인했다. 다만 최종 재대조에서는 계산값의 추가 변경을 감지했다. 제가 수행한 실사용 동작은 탭·열기·닫기에 한정돼 원인을 단정하지 않았고, 사용자에게 확인했으며 직접 변경하지 않았다는 답변을 받았다. 실사용 검사 중 의도하지 않은 변경으로 기록하고 현재 값을 보존했다. 최종 상태까지 원본과 동일하다고 주장하지 않는다. QA 설정과 실사용 설정은 서로 다른 파일이고, 변경된 실사용 값도 QA 입력과 일치하지 않는다. 계산값·장비·프리셋을 편집하지 않았고 실사용 노트 생성·삭제·실패 주입을 하지 않았다. 실사용 데이터를 별도 QA의 입력으로 쓰지 않았다.
- 관측 불일치를 곧바로 플러그인 결함이나 앱 정지로 판정하지 않았다. 제한된 재연결/새 관측 시도 이후 추가 실사용 조작을 중단했으며 앱 강제 종료나 재설치를 하지 않았다. 실사용 콘솔의 미처리 예외를 직접 관측한 검사는 아니다.
- 개인 입력값·화면·보관함 경로는 이 보고서/QA 자료에 복제하지 않았다. 검사 전 비교용 설정 스냅샷은 로컬 ignored dist/post-release-private에만 있다.

## 별도 보관함의 공개 배포본 검증

GitHub1.3.4에서 main.js·manifest.json·styles.css를 새로 내려받고 이전 공개 해시와 일치함을 확인했다. `/private/tmp/photo-field-qa-profile`과 `/private/tmp/photo-field-qa-vault`의 macOS Obsidian 실제 ItemView에 그 파일을 적용했다. `app.emulateMobile(true)`, Playwright/CDP 모바일 뷰포트·터치 활성화를 사용했다. iPhone 미러링은 사용하지 않았다.

| 항목 | 결과 |
|---|---|
| 권장 출력 적용·취소 | 통과. 출력만 변경, ISO·조리개·거리 유지, 이전 출력 복원 |
| 상세 설정 이동·결과 복귀 | 통과. 카메라/플래시 접근, 결과 복귀 및 펼침 유지 |
| 존 역산·적용 | 통과. 목표2–5m 제안 적용 후 목표 포함, 불가 조건 제한 연결 |
| APS-C 환산·실제 노출 분리 | 통과. 실제35mm f/2→화각52.5mm/심도 약f/3, 내부/플래시 표시의 실제f/2·ISO100·출력 유지 |

핵심12묶음 + cm/m 회귀4묶음 통과. 새 실행의 pageerror0. 자동 회귀82/82도 통과. 관찰한 범위에서 새 제품 실행 오류나 배포 파일 불일치가 발견되지 않았다. 가로/축소 화면에서 기존 Obsidian 도구막대가 콘텐츠 위를 지나가며 세로 스크롤이 필요한 한계는 유지된다. 일부 그림 밖 거리의 장면 축 라벨은 좁은 화면에서 조밀하게 보인다. 실행 차단 오류와 구별한다.
