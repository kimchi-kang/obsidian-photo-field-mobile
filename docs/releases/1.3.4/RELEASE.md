# 사진 촬영 도우미 1.3.4 · 결과에서 바로 조정

촬영 현장에서 결과를 읽고 설정하는 흐름을 줄였습니다. 기존 바우하우스 디자인·촬영 장면·계산 엔진·장비 사양·저장 형식은 유지합니다.

- 현재 거리의 노출 차이 바로 아래에 권장 지원 출력과 잔여 EV를 표시합니다. 한 번 눌러 계산 도구의 출력값만 적용하고, 적용 취소로 이전 출력에 돌아갈 수 있습니다. 실제 카메라나 플래시를 제어하지 않습니다.
- 최대·최소 출력 한계, GN 누락, 장비 미지원 이론값은 계속 표시합니다. 계산 불가 시 적용 버튼이 비활성화되고 조건 확인으로 연결됩니다.
- 상세 설정에 ‘결과로 돌아가기’를 추가하고 화면 상단에 현재 탭의 촬영 조건을 요약했습니다.
- 존 역산을 목표 입력 → 제안과 현재값→변경값 확인 → 적용 → 목표 포함 확인 순서로 정리했습니다. 전문 설정은 펼쳐서 확인하고, 달성 불가 시 렌즈 제한 설정으로 이동할 수 있습니다.
- 실제 설정과 풀프레임 대응값을 한 문장으로 읽도록 정리했습니다. 노출·플래시 계산에는 실제 조리개를 사용합니다.
- 저장 버튼 이름을 현재 탭에 맞추고 저장한 노트를 직접 여는 동작을 추가했습니다. 자동 화면 전환은 하지 않습니다. 저장 버튼의 hover 대비도 수정했습니다.

검증: 자동82개, 별도 macOS Obsidian 모바일 에뮬레이션41개 검사 묶음 통과. 360×800·390×844·844×390·390×440, 라이트·다크·큰 글씨·4탭의64개 상태를 캡처하고 대표 화면을 직접 확인했습니다. 기존 GN 커서·cm/m 입력 고정·초안·삭제 복구·저장 병합/재시도·탭별 저장·터치 제스처를 재검사했습니다. **iOS·Android 실기 검증은 아닙니다.**

합성 QA에서 거리 변경→권장 확인→적용의 명시적 조작은3→2회, 존 목표 입력부터 적용 버튼까지의 간격은 약576→326px로 줄었습니다. 실제 사용자 연구나 실제 키보드·손가락 탭 수를 측정한 결과가 아닙니다.
