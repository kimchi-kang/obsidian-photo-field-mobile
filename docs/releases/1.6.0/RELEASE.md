# 사진 촬영 도우미 1.6.0 · 필름카메라 기준·필름면 거리·새 슬라이더

## 필름카메라 기준 (참고 바디 Nikon FM2)

- 새로 시작할 때의 기본값: 35mm 필름 36×24mm, 50mm, f/4, ISO 400, CoC 0.03mm.
- 필름 감도는 12~6400, 조리개는 한 스톱 단위(슬라이더도 한 스톱씩), 초점거리는 니코르 단렌즈 구성.
- 포맷 목록은 35mm·하프프레임·645·6×6·6×7 필름이 먼저 나오고 디지털 포맷도 남아 있습니다.
- "센서"는 "필름·포맷", "풀프레임 환산"은 "35mm 환산"으로 바꿨습니다.
- TTL·HSS에는 "FM2 미지원"을 표시하고, 동조 1/250초 이하 안내를 넣었습니다.

## 거리 기준이 필름면으로 바뀌었습니다

- 초점 맞출 거리, 근거리, 원거리, 과초점, 존 포커싱 목표가 모두 렌즈 거리 눈금과 같은 필름면 기준입니다. 렌즈에 새겨진 숫자와 그대로 맞출 수 있습니다.
- 이전 버전(렌즈 주평면 기준)과는 대략 초점거리만큼 차이가 납니다. 50mm면 약 5cm이고 가까울수록 차이가 큽니다. **같은 입력이라도 결과 숫자가 이전과 조금 다릅니다.**
- 필름면에서 초점거리의 4배보다 가까운 거리(50mm면 20cm 미만, 등배 이상의 접사)는 계산하지 않고 안내 문구를 보여 줍니다.
- 프레임 크기는 무한대 화각 근사 대신 실제 배율로 계산합니다.
- 박막렌즈 모델이라 실제 렌즈의 눈금과는 조금 다를 수 있습니다.

## 화면

- 거리는 화면·표·그림·저장 노트 모두 소수 첫째 자리까지만 표시합니다. 저장값과 계산 정밀도는 그대로입니다.
- 슬라이더를 눈금 자 위의 알약형 지시침으로 바꿨습니다.
- 빨간 포인트를 늘렸습니다: 결과 단위, 결과 카드 모서리, 전체 심도 칸, 초점면, 셔터 버튼, 선택된 즐겨찾기·거리·∞, 입력 중인 숫자.

## 데이터

- 이미 저장된 설정·장비·즐겨찾기는 바꾸지 않습니다. 새 기본값은 값이 없는 항목에만 적용됩니다.
- CoC 모드에 "필름"이 추가되었습니다. 기존 "대각/1500"과 "직접 입력"은 그대로입니다.

## 검증

자동 테스트 108개, 모바일 에뮬레이션 QA 17개 통과. 계산은 독립 검산(이분법으로 렌즈 위치를 구해 착란원을 직접 계산)과 무작위 표본으로 대조했습니다. 실제 iOS·Android 기기에서는 검증하지 않았습니다.
