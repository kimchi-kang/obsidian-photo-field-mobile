# 사진 촬영 도우미 1.4.1 설치·복구

현장 연속 사용 검증을 마친 1.4.1입니다. 승인된 현장 사용 후보와 main.js·manifest.json·styles.css는 동일하며 ZIP에서는 설치 안내만 배포용으로 갱신했습니다. 사용자 data.json과 테스트 데이터는 포함하지 않습니다.

## 업데이트

BRAT에서 kimchi-kang/obsidian-photo-field-mobile의 latest 업데이트를 확인하세요. 수동 설치는 기존 플러그인 폴더 전체를 백업하고 플러그인을 끈 뒤 ZIP의 프로그램·라이선스 파일을 기존 폴더에 복사합니다. **data.json을 지우거나 덮어쓰지 마세요.** 플러그인을 다시 활성화해 기존 설정을 확인하세요.

1.4.0 대비 데이터 형식이나 마이그레이션은 바뀌지 않습니다. 입력·장비·초안·즐겨찾기·거리·화면 상태를 유지합니다. GN·심도·존 계산 엔진과 장비 사양도 동일합니다.

## 수정 내용과 사용

- 실제 저장 파일을 확인해 조용한 저장 실패를 감지합니다. 저장 위치·권한을 해결한 뒤 화면의 저장 재시도를 누르세요. 미저장 상태에서 앱을 닫으면 마지막 변경은 사라질 수 있습니다.
- 간편 존 화면의 렌즈 한계 확인은 실제 상세 조리개 제한으로 이동합니다.
- 장비 줌별 GN 누락에 맞는 원인·해결 안내를 제공합니다.
- 거리 선택 뒤 더보기를 접습니다. 오프카메라 거리 버튼은 플래시 거리만 변경합니다.
- 권장 출력 적용 취소의 범위를 명확히 하고 새 적용 뒤 오래된 만료 안내를 없앴습니다. 수동 출력 조절 뒤 이전 권장 적용 취소는 안전을 위해 만료됩니다.

촬영 즐겨찾기→거리→EV 확인→권장 출력 적용은 기본 3탭, 존 목표 선택→역산 확인→명시적 설정 적용은 기본 2탭입니다. 작은 화면·가로·큰 글씨에서 스크롤은 필요할 수 있습니다.

## 1.4.0 복구

플러그인을 끄고 첨부한 photo-field-mobile-1.4.0.zip의 프로그램·라이선스 파일로 교체하세요. 같은 데이터 형식이므로 현재 data.json을 유지합니다. 데이터 자체가 손상된 경우에만 설치 전 백업을 복구하고, 백업 이후 변경이 사라질 수 있음을 확인하세요.

자동 95개·strict 빌드·별도 macOS Obsidian 실제 ItemView 연속 상황·모바일 12개 화면 조합을 검증했습니다. 실제 휴대전화 키보드·야외 가독성·한 손 조작·시험 촬영/광량 측정은 미검증입니다. 라이선스와 서드파티 고지를 함께 보관하세요.
