# 1.4.1 설치·공개 배포 기록

사용자가 현장 사용 수정 후보의 실사용 설치와 공개 배포를 승인했다. 기존 후보 및 검증 보고서의 “미승인/미설치” 표시는 당시 상태이며 승인 이후 상태는 이 문서와 publication.json을 기준으로 한다.

## 실사용 설치

- Obsidian이 종료된 상태를 확인하고 기존 1.4.0 플러그인 폴더 전체를 로컬 비공개 dist 아래에 백업했다.
- 승인된 후보와 같은 프로그램·라이선스 파일만 교체했다. data.json·플러그인 활성화 목록·사용자 노트는 교체하지 않았다.
- 실사용 Obsidian을 열어 플러그인 로드·화면의 1.4.1·저장 오류 없음·기존 입력/장비/즐겨찾기와 디스크 일치를 확인했다.
- 설치 전·복사 후·활성화 및 화면 확인 후 data.json은 바이트 단위로 동일했다. 사용자 촬영값을 검사 목적으로 변경하지 않았다.
- 개인 보관함 경로·실제 설정·화면·설정 파일 해시는 ignored dist에만 보관하며 공개 자료에 포함하지 않는다.

## 공개 배포 구성

승인된 후보의 실행 파일은 변경하지 않는다. 공개 ZIP에는 배포용 설치·복구 안내와 라이선스를 포함하며 사용자 데이터는 제외한다. main.js·manifest.json·styles.css·라이선스·서드파티 고지·설치 ZIP·1.4.0 복구 ZIP·SHA256 목록을 첨부한다. 현재 작업과 무관하게 이미 존재하던 미커밋 테스트 수정과 BRAT/이전 배포 기록은 이번 커밋에 포함하지 않는다.

첨부 파일·태그·실사용 설치본의 최종 일치 확인 결과는 publication.json에 기록한다.
