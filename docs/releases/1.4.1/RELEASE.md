사진 촬영 도우미를 연속 사용하며 확인한 불편 5가지를 최소 수정했습니다. 새 기능·디자인 개편·계산 엔진·장비 사양 변경은 없습니다.

- 조용히 실패하던 설정 저장을 실제 파일 확인으로 감지하고 기존 저장 재시도와 연결.
- 간편 존 화면의 렌즈 조리개 한계 확인을 실제 설정 위치로 연결.
- 장비에 없는 줌의 GN 누락 원인과 해결 안내 수정.
- 거리 선택 뒤 더보기를 접어 결과를 밀어내던 문제 완화.
- 권장 출력 적용 취소의 범위를 명시하고 새 적용 뒤 남던 과거 만료 안내 제거.

야간 플래시→존 포커싱→근거리→오프카메라→중단/노트/복귀를 이어 수행했습니다. 기본 즐겨찾기→거리→권장 출력 적용은 3탭입니다. 자동 95개, strict 빌드, 별도 macOS Obsidian 실제 ItemView 모바일 12개 화면 조합을 확인했습니다. 실제 휴대전화 키보드·야외 햇빛·한 손 조작·실제 시험 촬영은 미검증입니다.

1.4.0과 데이터 형식이 같으며 기존 설정·장비·즐겨찾기·초안을 유지합니다. 먼저 플러그인 폴더를 백업하고 **data.json은 덮어쓰지 마세요.** 첨부한 1.4.0 ZIP으로 코드만 복구할 수 있습니다.
