## 업데이트

BRAT에서 kimchi-kang/obsidian-photo-field-mobile의 latest 업데이트를 확인하세요. 수동 설치는 기존 플러그인 폴더 전체를 백업하고 플러그인을 끈 뒤 ZIP의 프로그램·라이선스 파일을 기존 폴더에 복사합니다. **data.json을 지우거나 덮어쓰지 마세요.** 다시 활성화해 기존 설정을 확인하세요.

1.4.1과 데이터 형식이 같으며 입력·장비·초안·즐겨찾기·거리·화면 상태를 그대로 사용합니다. 마이그레이션은 없습니다.
