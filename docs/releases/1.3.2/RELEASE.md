# 사진 촬영 도우미 1.3.2 · 가까운 거리는 cm로 자동 표시

1m 이하 거리는 cm, 1m 초과는 m로 자동 표시합니다. 0.5m는 50cm, 1m는 100cm, 1.5m는 1.5m입니다.

- 거리 입력칸·플래시 예상 거리·심도·존 목표·그림 눈금과 거리 표·프레임·저장 결과에 같은 규칙을 적용합니다.
- 입력 중에는 현재 표시 단위를 고정하고, 편집을 마치면 자동 변환합니다. 예를 들어 50cm 입력칸에서 150을 입력하면 1.5m가 되며 중간에 100배로 튀지 않습니다.
- 매우 작은 양수 거리를 0cm로 숨기지 않고 표시 정밀도 미만으로 안내합니다.
- 내부 계산과 저장 데이터는 기존 m를 유지합니다. GN의 m/ft와 렌즈·CoC의 mm는 바꾸지 않습니다. Markdown 입력표의 정확한 원본 m 값도 보존합니다.

검증: 자동82개 통과, 별도 Obsidian 모바일 에뮬레이션에서 편집 양방향·정확한 1m 경계·슬라이더·존 역산 적용·저장·재진입 복원·그림 축·거리 카드·프레임 표시4묶음 통과. 360/390px 및 가로 화면 넘침을 검사했습니다. 실제 iPhone 실행은 검증하지 않았습니다.

검사 도중 첫 축 검사는 선 요소를 선택했고, 다음 프레임 검사는 접힌 details의 보이는 텍스트만 읽어 실패했습니다. 검사 선택자를 눈금 텍스트로 고치고 실제 상세창을 펼쳐 최종 통과했으며 제품 기대값은 바꾸지 않았습니다. 첫 시도 로그는 같은 폴더에 보존합니다.

기존 계산 설정과 장비 데이터 형식을 유지합니다. BRAT은 latest 추적과 시작 시 자동 업데이트가 켜져 있으면 새 릴리스를 확인할 수 있습니다. 수동 교체 시 기존 플러그인 폴더를 백업하고 main.js·manifest.json·styles.css만 교체하세요. data.json은 덮어쓰지 않습니다.
