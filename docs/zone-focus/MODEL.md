# 존 포커싱과 풀프레임 환산 · 1.3.0 후보

기준: 작업 시작 시 1.2.0 + 당시 미커밋 Q20III·입력 커서·슬라이더·모바일 안정화 수정. 기존 `engine.ts` 정방향 광학/플래시 코드를 변경하지 않았다. 모델별 카메라 프리셋은 추가하지 않았다. APS-C의 치수는 일반적인 계산용 예시이며 특정 카메라의 공식 치수를 뜻하지 않는다. 자신의 센서 실치수가 다르면 직접 입력한다.

## 사용

- 존 포커싱 탭 → 현재 설정으로 확인: 센서·실제 mm·실제 f값·초점 맞출 거리(m)·CoC로 허용 근/원거리·전체 심도·과초점거리 확인. 장면 피사체를 좌우 드래그하거나 숫자/슬라이더로 거리 변경.
- 원하는 촬영 구간으로 역산: 목표 근/원거리(또는 무한대), 렌즈 f값 하한/상한, 실제 가능한 조리개 단계 입력. 목록 기본값은 일반적인 표시 단계 예시이며 장비에서 선택 가능한 값으로 편집할 수 있다. 가장 개방된 유효 단계를 우선한다.
- 결과의 '역산 결과를 현재 설정에 적용' 버튼을 눌러야 실제 계산 설정이 바뀐다. 장비를 원격 제어하지 않는다. 조리개·초점 변경에 따른 플래시 결과 변화는 실제 설정 변경의 결과이며 환산 표시 자체는 어떤 노출 입력도 바꾸지 않는다.
- 존 탭의 '현재 탭 결과 저장'은 GN·플래시 줌·ISO 오류와 독립적이다. 전체 저장은 기존과 같이 전체 계산 조건이 필요하다.

## 유한 목표 구간 역산

길이 a(목표 근거리), b(목표 원거리), s(초점 맞출 거리), f(실제 렌즈 초점거리), c(CoC)를 모두 mm로 맞춘다. N은 실제 f-number다.

기존 엔진:

```
h = f²/(N c), H = h + f
Dnear = h s / (h+s−f)
Dfar  = h s / (h−s+f), s ≥ H이면 ∞
```

a > f, b > a인 유한 구간에서 양 경계에 동시에 접하도록 풀면:

```
s* = 2ab/(a+b)          (산술평균이 아닌 조화평균)
h* = [2ab−f(a+b)]/(b−a)
Nrequired = f²/(c h*)
```

각 경계를 포함하는 조건이 허용하는 h의 최댓값이 이 교차점이다. h가 클수록 N이 작으므로, 이를 통해 가장 개방된 이론 조리개를 구한다. 구현은 오버플로를 줄이도록 같은 식을 a/b 형태로 평가한다. 입력한 실제 단계 중 렌즈 하한/상한 안의 f값을 오름차순으로 탐색한다. 각 단계의 s*를 **변경하지 않은 기존 optics()에 넣어** 목표 전체 포함을 재검증하고, 처음 성공한 단계를 제안한다. 포함 비교의 수치 허용 오차는 1e−9m이며 물리적인 추가 선명도 허용을 뜻하지 않는다.

실패하면 가장 조인 실제 단계의 결과를 한계 대안으로 표시하며 목표 포함을 보장하지 않는다고 설명한다. 더 먼 근거리/더 가까운 유한 원거리/더 짧은 실제 렌즈 mm가 재계산할 대안이다.

## 무한대 목표

원거리 ∞는 s≥H에서만 성립한다. s=H일 때 Dnear=H/2이므로, a~∞ 조건은 H≤2a다.

```
h* = 2a−f
Nrequired = f²/[c(2a−f)]
```

각 실제 단계에서 초점을 그 단계의 H에 둔 뒤 정방향 엔진으로 재검산한다. 무한대는 유한 큰 숫자로 대체하지 않는다. 장면 밖의 유한 값은 화살표와 실제 숫자, 무한대는 ∞로 별도 표시한다. 목표는 빗금·파선·라벨, 실제 심도는 실선·음영·라벨이다. 장면에는 현재 적용된 설정이 그려지며 미적용 제안을 실제 설정처럼 그리지 않는다.

## 예시

풀프레임 36×24mm, 실제 35mm, CoC=대각/1500≈0.0288444mm, 목표 2~5m, 단계 6.3 다음 7.1:

- 이론 필요 f/6.44939, 초점 맞출 거리 2.857142857m.
- f/6.3은 부족, 실제 단계 f/7.1을 선택.
- 기존 엔진 재검산: 약 1.94125~5.40926m로 목표 전체 포함.

## 풀프레임 환산

명목 프리셋: FF 1×, APS-C 1.5×, APS-C 1.6×, MFT 2×. 사용자 센서는 실치수 비율을 사용한다. 사용자가 실치수 기준을 고르면 어떤 프리셋에서도 대각 비율을 사용한다.

```
kdim = hypot(36,24) / hypot(width,height)
f_eq = f × k
N_eq = N × k
```

APS-C 1.5×의 실제 35mm f/2 → 화각 환산 52.5mm · 심도 대응 약 f/3. 1.6× → 56mm · 약 f/3.2. 실제 노출은 계속 f/2다. 예시 23.6×15.6mm의 실치수 비율은 약 1.5294×로 명목 1.5×와 다르므로 두 계수를 함께 공개한다. 실제 화각과 심도는 항상 실제 센서 치수·실제 mm·실제 N·실제 CoC만 사용하며 환산값을 재입력하지 않는다.

동일 촬영 위치·구도와 비교 가능한 감상 조건에서만 근사 심도 대응이다. CoC도 해당 감상 조건으로 대응시켜야 한다. 기본 대각/1500은 실치수 비율에서 이에 대응하나 명목 비율과 차이가 있다. 사용자 CoC는 직접 비교 조건이 달라질 수 있음을 환산값 바로 아래 경고한다. 테스트는 실치수에 맞춘 FF CoC와 원거리 심도가 근사 일치하는지도 검증한다. 박막렌즈의 f항 때문에 유한 거리에서 정확한 대수적 동일성을 주장하지 않는다. 근접 촬영·브리딩·다른 화면비에서 완전 일치를 보장하지 않는다. 화면비가 다르면 대각 기준임을 표시하고 실제 수평·수직·대각 화각을 별도 제공한다.

## 저장·마이그레이션

기존 version:2 저장 형식을 호환 확장한다. 새 입력만 기본값을 보충하며 기존 입력·장비 ID·장비 표·초안·삭제 복구·수동 GN 상태를 보존한다. 새 필드가 없는 기존 입력은 `migrationBackup`에 원본을 보관한다. 기존 백업이 있으면 덮어쓰지 않는다. 빈 숫자 편집 중에는 기존 정책대로 마지막 유한 값을 보존한다. 존 흐름·목표·무한대·조리개 범위/단계·환산 기준은 저장·복원된다. Markdown은 현재 실제 결과와 미적용 제안을 구별하고 입력·목표·기준·가정을 함께 기록한다.
