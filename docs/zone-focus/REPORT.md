# 사진 촬영 도우미 1.3.0 설치 후보 · 2026-10-29

구현·계산 검사·별도 macOS Obsidian 모바일 검사·설치 후보 준비 완료. 실사용 보관함 적용, GitHub 공개 릴리스, 앱 강제 종료는 하지 않았다.

## 보존한 기준

시작 시 manifest/package는 1.2.0. `Documents/Codex/AGENTS.md`, `.codex/AGENTS.md`를 읽고 근접 지침을 검색했다. 기존 미커밋 `src/presets.ts`, `src/view.ts`, `styles.css`, `main.js`, 기존 QA 기록을 확인했다. Q20III 추가·선택과 초안 보존, GN 커서, 큰 숫자 배치, 조사각 오류 분리, native range thumb 정렬을 유지했다. 기존 미커밋 diff는 `before/existing-changes.patch`, 변경 전 관련 소스와 번들은 `before/`에 보존했다. 이전 QA 결과 폴더를 덮어쓰지 않고 재실행 결과는 `regressions/`에 분리했다.

## 구현·사용법

- 존 포커싱 탭에 현재 설정 확인과 목표 구간 역산 제공. 초점 맞출 거리(m)와 실제 렌즈 mm를 구별한다.
- 유한 구간은 조화평균으로 초점을 구하고, 무한대는 과초점거리 기반으로 계산한다. 입력한 실제 조리개 단계 중 목표 전체를 포함하는 가장 개방된 값을 기존 엔진으로 재검산한다. 적용은 명시적 버튼으로 한다.
- 목표는 빗금/파선/라벨, 실제 심도는 실선/음영/라벨로 표시한다. 목표 포함·일부 부족·달성 불가와 대안을 안내한다.
- 명목 1.5×/1.6×와 실치수 대각 기준을 선택할 수 있다. 실제 치수 기반 계수·수평/수직 화각·CoC 비교 조건을 공개하며, 실제 노출과 심도 엔진에 환산값을 다시 넣지 않는다.
- 존 입력·환산 기준 저장/복원, 기존 설정·장비를 보존하는 호환 마이그레이션, 입력·실제 결과·목표·제안·가정을 담은 Markdown 저장. 플래시가 잘못되어도 존 탭 저장은 독립적이다.
- 화면 상단에 manifest에서 읽은 현재 버전(v1.3.0)을 표시한다. 작은 화면은 4개 탭을 2×2로 배치하며 기존 바우하우스 색·장면·타이포·조작부 방향을 유지한다.

명목 APS-C 1.5×: 실제 **35mm f/2 → 풀프레임 화각 52.5mm, 심도 대응 약 f/3**. 실제 노출은 f/2다.

역산 예시: FF 36×24mm, 실제 35mm, 기본 CoC, 목표 2~5m → 초점 약 **2.857m**, 실제 **f/7.1**, 검산 **1.941~5.409m**. 이론 필요 f/6.449를 넘어서는 실제 단계로 f/7.1을 선택하며 f/6.3은 목표 전체를 포함하지 못한다. 공식·도출·가정은 [MODEL.md](MODEL.md)에 정리했다.

## 검증 결과

- `npm run build`: strict TypeScript와 최종 번들 빌드 통과.
- `npm test`: **64/64 통과**. 기존 55개 + 새 9개. 환산 1×/1.5×/1.6×, 대각 비율, 노출 불변, crop 이중 적용 방지, CoC 대응, 유한/무한 역산 다중 조건 탐색, 단계 반올림 후 포함, 과초점 경계, 잘못된 입력, 렌즈 제한, 마이그레이션·Markdown 검사. `calculation-tests.txt` 참조.
- `node tests/zone-mobile.mjs`: **7/7 묶음 통과**, uncaught error 0. 실제 1.3.0 번들을 실행하는 ItemView 검사.
- `node tests/zone-evidence.mjs`: 현재 설정 3m·명목 환산 예시·FF 35mm 2~5m 역산 예시 추가 검사 및 캡처 통과.
- 기존 스크립트 재사용: GN/큰 숫자/심도 저장/커서 **4/4**, Q20III 장비/초안/노트/복원 **3/3**, 슬라이더 트랙/썸 정렬 및 CDP 터치 **2/2**, 기존 모바일 호스트·장비 편집/삭제 복구/스크롤/44px **5/5** 통과. 새 결과 폴더에서 재실행하는 `tests/zone-regressions.mjs` 제공. 원본 테스트 내용은 보존했다.

### 실제 QA 환경

- macOS Obsidian 1.14.5, `/private/tmp/photo-field-qa-vault`, `/private/tmp/photo-field-qa-profile`, 로컬 CDP 9338.
- `app.emulateMobile(true)`, CDP `mobile:true`, 실제 `Input.dispatchTouchEvent` 사용.
- 360×800 / 390×844 / 430×932 / 844×390, 라이트·다크, 기본/20px 글씨. 추가 390×440 / 844×260을 키보드로 가용 높이가 줄어든 상황의 대리 검사로 사용. 실제 iOS 키보드가 실행된 검사는 아니다.
- 소수 입력과 커서, 무한대 전환, 명시적 적용, 터치 드래그/슬라이더/세로 스크롤, 모든 탭 전환과 재진입, 설정 복원, Markdown 내용, 긴 값·오류·실제 하단 도구막대 위 저장 버튼 도달성 검사.
- 네이티브 숫자 입력과 select의 긴 값은 자체 스크롤/축약 동작을 사용한다. 선택 센서 치수·명목 계수는 바로 아래 보조 설명에도 전체 표시한다.

### 직접 본 캡처와 수정

변경 전 `before/390-844-light-dof.png`, 변경 후 `after/example-2m-5m-scene.png`, `after/equivalent-35mm-f2-15x.png`, `after/example-2m-5m-result.png`, `after/390-target-infinity.png`, `after/long-finite-error.png`, 작은 화면·가로·다크·큰 글씨 캡처를 직접 열어 확인했다. 전체 `after/`에 50장 이상 실제 화면 증거가 있다.

첫 실행에서 사용자 CoC 경고가 접힌 details에만 있었고, 매우 긴 거리 라벨은 SVG 안에서 잘릴 위험이 있었다. 경고를 환산값 바로 아래에 노출하고, 장면에는 짧은 '그림 밖' 라벨·아래 줄에는 유한한 실제 값을 표시하도록 수정했다. `first-run/`에 첫 실행 로그와 화면을 보존했다. 첫 실행의 복원 검사 차이는 빈 GN/줌을 마지막 유한 값으로 복원하는 기존 정책 때문이어서 기대값을 저장된 스냅샷과 비교하도록 바로잡았다. 최종 실행은 모두 통과했다.

단순 HTML 목업, iPhone 미러링, 창 폭만 줄인 데스크톱 화면으로 대체하지 않았다. 화면 캡처는 스크롤 위치에 따라 호스트 헤더나 도구막대 아래 일부 내용이 보일 수 있다. 별도로 스크롤하여 저장 버튼 중앙이 실제 클릭 가능한지도 확인했다.

## 설치 후보와 복구

- `dist/photo-field-mobile-1.3.0-zone-candidate.zip`: 최종 검사한 main.js·manifest.json·styles.css와 라이선스/계산 문서.
- `dist/photo-field-mobile-1.2.0-pre-zone-recovery.zip`: **이번 작업 시작 시의 미커밋 수정을 포함한** 원래 번들/manifest/styles. 더 오래된 Git 버전으로 되돌리는 파일이 아니다.
- SHA256 및 파일별 검증: `package-verification.json`, `SHA256SUMS.txt`. ZIP에는 data.json·보관함·사용자 노트가 없다.

수동 적용 전 해당 보관함의 `.obsidian/plugins/photo-field-mobile/` 전체, 특히 `data.json`을 별도로 백업한다. 플러그인만 비활성화하고 후보의 main.js·manifest.json·styles.css를 같은 폴더에 복사한 뒤 활성화한다. data.json을 덮어쓰지 않는다. 문제가 생기면 플러그인 비활성화 후 복구 ZIP의 같은 세 파일을 되돌리고 다시 활성화한다. 설정도 설치 전으로 되돌리려면 별도 백업 data.json을 함께 복원한다. 새로 만든 Markdown 노트는 자동 삭제하지 않는다.

실사용 보관함에 이 후보를 설치하거나 GitHub에 공개하려면 대상과 작업 범위를 특정한 추가 승인이 필요하다. 현재는 후보 생성까지만 완료했다.

## 실기에서만 남은 항목

실제 iOS/WKWebView의 숫자 키보드·소수점 입력, 키보드와 safe-area 동시 변화, VoiceOver, 기기 글자 확대, 실제 iOS 제스처/백그라운드 전환/저사양 성능은 미검증이다. macOS 에뮬레이션 결과를 실기 통과로 표현하지 않는다. 광학 모델 자체도 CoC 기반 허용 범위이며 실제 렌즈 근접 촬영·브리딩·동공 배율·회절/수차의 복합 효과까지 실측 보장하지 않는다.

추가 최종 확인: 상단 버전 표시를 추가한 뒤 QA Obsidian의 기존 manifest 캐시를 재조회하도록 검사 스크립트를 보완하고 v1.3.0 표시와 모바일 전체 배치를 재검증했다.
