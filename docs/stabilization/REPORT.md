## 저장 정책과 한계

첫 요청부터80ms 창을 열고 뒤 입력으로 타이머를 계속 미루지 않는다. 쓰기 중 들어온 입력은 최신 스냅샷 하나로 합쳐 그다음에 기록한다. 숫자를 지우기 직전의 마지막 유한값은 별도 스냅샷으로 보존한다. 조작 종료(change/focusout/피사체 pointerup/cancel), 화면 닫기, 앱 숨김/pagehide, 플러그인 종료에서 flush를 시도한다. 실패하면 최신 상태를 메모리에 남기고 오류 알림/화면 상태와 ‘설정 다시 저장’을 제공한다. 비동기 종료 훅을 OS가 끝까지 기다린다고 보장할 수 없으며, 강제 종료/전원 상실이나 저장이 끝나기 전 재시작의 완전 보존을 주장하지 않는다.

## 실제 기기 확인 범위

실제 iOS 통과: 없음. 실제 Android 통과: 없음. iOS Simulator/Android Emulator 검증: 없음.

iPhone 미러링을 열었지만 ‘iPhone 사용 중 · 연결하려면 iPhone을 잠그십시오’ 상태로 연결되지 않았다. USB 장치 목록에서 테스트 기기 확인 불가, Xcode devicectl/xctrace와 Android adb도 제공되지 않았다. 사용자의 폰을 잠그거나 앱을 강제 종료하지 않았다.

미확인: iOS 소수 키보드/IME·지우고 재입력, Android 뒤로가기/키보드 닫기, 실제 회전·키보드·노치 안전영역·시스템 큰 글씨, WebKit/Android WebView 터치 충돌, 실제 앱 강제 종료 후 복원, 각 기기의 오프라인 저장/재실행/동기화. 에뮬레이션의 축소 뷰포트는 실제 키보드 검증이 아니다. 큰 글씨는360×800에서 root/rem 글꼴20px로 대리 검사하여 가로 넘침 없음·표시 컨트롤44px 이상을 확인했다(`large-text.json`). 이는 시스템 접근성 설정 검증과 구분한다.
