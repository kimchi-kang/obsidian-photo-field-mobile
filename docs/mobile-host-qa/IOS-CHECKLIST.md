# iOS 화면 기준 · 에뮬레이션 전용

최신 지시대로 실제 기기·추가 설치 없이 기존 macOS Obsidian만 사용했다. 사용자가 권한이 필요한 실행을 허용한 뒤 전용 앱/CDP 연결을 승인받아 실행했다.

- 실제 ItemView + app.emulateMobile(true) + CDP 모바일 메트릭/터치.
- 360×800·390×844·430×932·844×390, 라이트/다크, CSS 큰 글씨·축소 높이.
- 실제 Obsidian 시나리오69개 및 자동53개 통과. 제품 수정 없음.
- 실기·iOS WKWebView·네이티브 키보드·OS 뒤로가기·노치는 범위 밖이며 검사를 요청하지 않는다.

[최종 보고서](REPORT.md)와 [실행 환경](environment.json)을 참고한다. 이전 EPERM은 승인된 실행에서 해결됐다.
