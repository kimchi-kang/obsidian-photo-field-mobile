# 실제 장비 비교 기록

장비 모델·설명서·실측값이 아직 제공되지 않았다. 실제 장비 프리셋은 만들지 않았다. GN40과 QA 표는 연습·합성 검사값이며 아래 실제 장비 사양으로 사용하지 않는다.

## 장비와 출처

- 장비 모델 / 펌웨어: [사용자 입력]
- GN 출처: [설명서 URL·판본·페이지 또는 실측 절차]
- GN 숫자 / m·ft 단위 / ISO100 최대 출력 여부: [사용자 입력]
- GN 기준 줌 / 제조사 기준 포맷 / 현재 줌: [사용자 입력]
- 실제 지원 출력 단계 / 최소 출력: [사용자 입력]
- 직광·일반 동조 확인 / 셔터속도·동조 조건: [사용자 입력]
- 추가 손실 조건 / 손실 stop의 측정 또는 추정 근거: [사용자 입력]

## 한 번의 비교

| 항목 | 입력·관찰 |
| --- | --- |
| 날짜·환경광·배치 | [사용자 입력] |
| 선택 출력 / ISO / 조리개 | [사용자 입력] |
| 카메라→피사체 / 플래시→피사체 거리 m | [각각 입력] |
| 기준 GN / 단위 / 기준 줌 / 사용 줌 | [사용자 입력] |
| 추가 손실 L stop | [측정 또는 추정 명시, GN 포함 손실과 중복 금지] |
| 계산 예상 거리 d / 현재 거리 r에서 예상 EV | [앱 결과와 계산 노트 경로] |
| 사용자 확인 측정값 | [측정 장비·교정 상태·방법·반복 횟수, 없으면 미측정] |
| 촬영 관찰 | [카메라 설정·RAW/JPEG·히스토그램 등, 측정값과 별도] |
| 오차 | [동일 조건/동일 단위로 비교 가능한 항목만, 예: 측정 조리개 대비 EV; 측정 없으면 산출 불가] |
| 미확인 조건 | [실제 배광·반사율·환경광·거리 기준·광축·손실 등] |

GN은 수동·직광·일반 동조 중심부 노출의 추정이다. 절대 조도나 실제 사진의 겉보기 밝기를 정확히 예측하지 않는다. 사진 밝기 관찰만으로 GN을 자동 보정하지 않는다. 확인한 측정값과 관찰·추정은 구분한다. HSS·TTL·바운스는 비교 모델의 적용 대상에서 제외하며 새로운 계산 모델을 추가하지 않는다.
