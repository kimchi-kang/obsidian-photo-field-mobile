# 사용자 기기 확인 · 8~10분

실기 통과 기록이 아니라 **앞으로 실행할 절차**다. iOS와 Android 각각 실행한다. 앱 강제 종료·휴대전화 잠금은 필요 없다.

준비: 별도 로컬 테스트 보관함을 만들고 후보 ZIP의 `photo-field-mobile` 폴더를 `.obsidian/plugins/`에 설치한다. 실사용 보관함을 복사하지 않는다. 처음 플러그인을 활성화한 뒤 계산 화면을 연다. 설치 시간은 아래 8~10분에 포함하지 않는다. iOS에서 숨김 폴더 복사가 어렵다면 컴퓨터에서 만든 별도 테스트 보관함을 기기로 옮긴다. BRAT 최신 안정판은 이번 로컬 후보와 다르므로 후보 ZIP으로 테스트한다.

기록 머리말: 날짜 / 기기 모델 / OS / Obsidian 버전 / 플러그인1.2.0 + 후보 SHA256 / 보관함 저장 위치·동기화 방식 / 키보드 종류 / 글자 크기. 실패 시 해당 단계 번호와 **정확한 입력 순서·기대값·실제값·화면 캡처**를 함께 남긴다. 다른 노트와 개인정보는 캡처에서 제외한다.

정상 다시 열기와 OS가 프로세스를 종료한 뒤의 재실행은 다르다. 이 절차에서 앱 강제 종료를 요구하지 않는다. 앱이 메모리에 남아 있으면 ‘배경 복귀’로 기록하며 ‘프로세스 재실행’으로 보고하지 않는다. 저장 중 종료/전원 상실까지 보장하지 않는다.

저장 실패 알림이 나타나면 앱을 열어 두고 ‘설정 다시 저장’ → 오류가 사라지는지 → 화면 재진입 후 값 확인. 실패를 만들려고 실기 보관함 권한/폴더/저장 파일을 훼손하지 않는다. 설정·노트 I/O 실패 주입은 전용 macOS 테스트 앱에서 별도로 통과했다.

모든 단계를 통과해도 해당 기기·OS·앱 버전에 대한 결과만 기록한다. 반대 OS나 최소 버전1.7.4까지 통과한 것으로 확대하지 않는다.
